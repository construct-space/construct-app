# Car Dealer Landing Page — Plan

## Classification
**Type:** Marketing / e-commerce landing page  
**Scope:** Hybrid (lead generation + showroom + brand)  
**Stack:** Static HTML/CSS/JS or Nuxt (if backend integration needed)  
**Visual Direction:** Modern / contemporary SaaS aesthetic  
**Audience:** Car shoppers (cold → warm leads), dealership staff (admin)

---

## Identity & Visual System

### Color Palette
- **Dominant:** Neutral (off-white/light gray #F5F5F5, charcoal #1A1A1A)
- **Accent:** Bold blue or teal (e.g. #0066CC or #00A86B for CTAs)
- **Secondary:** Warm gray (#999999 for dividers, metadata)

### Typography
- **Display:** Clean sans (e.g. Inter, Söhne, Helvetica Now) — headline weight 600–700
- **Body:** Same sans, weight 400–500, 16–18px line-height 1.6
- **Captions:** Weight 500, size 12–14px, color gray

### Spacing & Grid
- 12-column responsive grid, 24px gutters (desktop), 16px (mobile)
- Generous whitespace between sections (64–80px vertical rhythm)
- Soft shadows on cards (`box-shadow: 0 2px 8px rgba(0,0,0,0.1)`)
- Subtle gradients on hero only (if any); otherwise flat color blocks

### Motion
- Fade-in on scroll (opacity 0 → 1, 300ms ease-out)
- Hover state on CTAs: color shift + slight scale (1.02x)
- No flashy transitions; smooth and professional

## Page Structure (8 screens)

### 1. **Hero / Above the fold**
- **Headline:** "Find Your Perfect Car" or dealership name tagline
- **Subheadline:** Value prop (e.g. "200+ vehicles in stock, 0% financing available")
- **CTA:** Primary button "Browse Inventory" + secondary "Schedule Test Drive"
- **Hero image:** High-quality car photo (right side) or video background
- **Layout:** Left-aligned text + right image, responsive stack on mobile

### 2. **Inventory Browser**
- **Search/filter bar:** Make, model, price range, body type, fuel type
- **Grid:** 3-column card layout (4 columns desktop, 2 mobile)
- **Card:** Thumbnail image, make/model, price, mileage, trim, "View Details" CTA
- **Pagination or "Load more":** Infinite scroll or numbered pages
- **Empty state:** "No results found. Adjust filters."

### 3. **Vehicle Detail (modal or full page)**
- **Gallery:** Main image + thumbnail carousel
- **Title & price:** Headline + financing estimate
- **Specs table:** Year, mileage, transmission, fuel, VIN, stock number
- **Description:** Condition notes, service history, features
- **CTA row:** "Schedule Test Drive" + "Get Financing Estimate"
- **Related vehicles:** 3–4 similar cars below

### 4. **Lead Capture / Contact Form**
- **Headline:** "Get Started" or "Request More Info"
- **Form fields:** Name, email, phone, interest (vehicle type / trade-in / financing)
- **Legal:** Privacy checkbox + link
- **CTA button:** "Submit" → success message
- **Layout:** 2-column form (name + email left, message right), single column on mobile

### 5. **Financing / Offers**
- **Section title:** "Financing Made Easy"
- **Card grid:** 3 cards (0% APR offer, trade-in value, lease vs buy)
- **Each card:** Icon + headline + brief description + "Learn More" link
- **Optional calculator widget:** Monthly payment estimator (form inputs → output)

### 6. **Testimonials / Social Proof**
- **Section title:** "What Our Customers Say"
- **Carousel or grid:** 3–4 quote cards (photo + name + quote + stars)
- **Layout:** Full-width carousel (desktop) or stacked cards (mobile)

### 7. **Service / Additional Info**
- **3–4 feature blocks:** e.g. "Free Inspection", "Extended Warranty", "Fast Delivery"
- **Icon + headline + 2-line description per block**
- **Layout:** 2×2 grid (desktop), stacked (mobile)

### 8. **Footer**
- **Columns:** Hours, address, phone, email, social links, navigation (Home, Inventory, About, Contact, Privacy)
- **Copyright:** Year + dealership name
- **Layout:** 4–5 columns desktop, 1 column mobile, light gray background

## Data Model & Interactions

### Inventory Data
**Source:** Static JSON or backend API  
**Fields per vehicle:**
- `id`, `make`, `model`, `year`, `price`, `mileage`, `transmission`, `fuel`
- `trim`, `vin`, `stock_number`, `image_url`, `description`, `features[]`
- `in_stock` (boolean)

**Interactions:**
- Filter/search triggers client-side or API call → re-render grid
- Click vehicle card → open modal or navigate to `/vehicle/:id` detail page
- "Schedule Test Drive" → scroll to form, pre-fill vehicle interest

### Lead Form Data
**Fields:**
- `name`, `email`, `phone`, `vehicle_interest`, `trade_in` (boolean), `message`
**On submit:**
- Validate client-side (name/email/phone required)
- POST to backend API or email service (Mailgun, SendGrid, etc.)
- Show success modal + clear form

## User Flows

### Cold visitor → Lead
1. Land on hero → reads headline/subheadline
2. Clicks "Browse Inventory" → scrolls to inventory grid
3. Filters by price/make → views filtered results
4. Clicks vehicle card → sees detail modal/page
5. Clicks "Schedule Test Drive" or "Get More Info" → scrolls/navigates to contact form
6. Fills form (name, email, phone) → submits
7. Receives confirmation modal + email confirmation (sent by backend)

### Warm visitor → Decision
1. Lands on hero with direct link to `/vehicle/:id` (shared by dealer)
2. Sees detail page → compares specs + pricing
3. Clicks financing calculator → estimates monthly payment
4. Calls dealership directly (visible in header/footer) or submits form

## File Structure & Build

### Tech Stack (Recommendation)
- **Framework:** Nuxt 3 (if backend/API needed) or static HTML + Vite (if JSON inventory)
- **Styling:** Tailwind CSS or vanilla CSS (12-column grid system)
- **State:** localStorage for filter history; transient for form data
- **Hosting:** Vercel, Netlify, or dealer's existing server

### Files to Create
```
/
├── index.html (hero + full page)
├── /inventory (or /vehicles)
│   ├── index.html (grid + filters)
│   └── /[id].html (detail page)
├── /about.html (dealership story)
├── /contact.html (full-page contact form, optional)
├── /css
│   ├── global.css (grid, typography, reset)
│   └── components.css (buttons, cards, modals)
├── /js
│   ├── inventory.js (filter + search logic)
│   ├── form.js (validation + submit)
│   └── modal.js (detail view)
├── /data
│   └── vehicles.json (static inventory or fetch from API)
└── /images (vehicle photos, hero, icons)
```

### Key Interactions to Build
1. **Inventory filter/search** → filter vehicles by make/model/price, re-render grid
2. **Vehicle detail modal/page** → expand card into full view + related cars
3. **Contact form validation** → client-side email/phone checks, submit handler
4. **Financing calculator** (optional) → JS formula: monthly = (price × rate) / months
