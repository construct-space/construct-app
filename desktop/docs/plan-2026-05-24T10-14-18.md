# Plan — Sara Motors landing page

## Classification

Single-page marketing site for a car dealership called **Sara**. Not a Construct Space, not a web app — a static landing page. Built as plain HTML + CSS + a tiny bit of JS for interactions (mobile nav, scroll reveals, contact form validation). No build step required, but we'll use Vite to make local dev pleasant and produce a clean `dist/`.

Aesthetic: modern SaaS / trust-tech. Think Carvana / Vroom / modern dealer chains — light theme, one bold accent color, soft gradients, big hero, structured inventory grid.

## Identity

- **Brand name**: Sara Motors
- **Tagline**: "Find your next car. Without the dealership games."
- **Voice**: confident, transparent, low-pressure. No exclamation marks, no "DEALS DEALS DEALS". Promises clarity, fair pricing, and a no-haggle process.
- **Palette**:
  - Background: `#FFFFFF` primary, `#F7F8FA` section alt
  - Ink: `#0B1220` (near-black), `#4B5563` (secondary), `#9CA3AF` (muted)
  - Accent: `#2563EB` (electric blue — trust + tech) with `#1D4ED8` hover and a subtle `#EFF4FF` tint background
  - Success accent (badges): `#059669`
- **Type**:
  - Display + headings: **Inter** (700 / 600) — clean, neutral, ubiquitous
  - Body: **Inter** (400 / 500)
  - Numerals tabular for prices/specs
- **Imagery**: high-quality car photography on neutral or dealership-floor backgrounds. Use Unsplash hot-linked images (curated list) so the page works out of the box without bundling assets.

## Pages

Single page, anchor navigation:

1. `/` — the landing page itself, sections:
   - **Nav** — sticky, glass-on-scroll. Logo (Sara Motors mark) + links: Inventory, Financing, About, Contact + a primary CTA "Browse Inventory".
   - **Hero** — left: H1 + subhead + two CTAs ("Browse Inventory", "Get pre-approved"). Right: hero photo of a featured car with a floating "price card" overlay (price, mileage, year, MPG). Trust strip below: "1,200+ cars sold · 4.9★ on Google · 7-day return policy".
   - **Value props** — 3-column row: *Upfront pricing* / *7-day returns* / *Financing in minutes*. Each with an icon, headline, one-sentence body.
   - **Inventory showcase** — section header "Featured inventory" + filter chips (visual only — All / SUV / Sedan / Truck / EV). Grid of **8 car cards**: photo, year + make + model, price (large, tabular), mileage, body type, "View details" link. Cards have hover lift.
   - **How it works** — 3-step horizontal timeline: *Browse* → *Test drive at home* → *Buy online or in person*.
   - **Financing** — split section: left a calculator-styled card (price, down payment, term, estimated monthly — all client-side math), right a copy block on financing partners + soft credit pull messaging.
   - **Testimonials** — 3 short quote cards with name + city + star rating.
   - **About Sara** — 2-column: photo + short founder story ("Sara started Sara Motors in 2018 after one too many bad dealership experiences..."). Stats row: years in business, cars sold, average rating.
   - **Contact / CTA** — gradient panel. Headline, short form (name, email, phone, message), submit button. Form validates client-side and shows a success state; doesn't actually POST anywhere (logs to console + shows toast).
   - **Footer** — logo, address, phone, hours, social links, secondary nav, "© 2026 Sara Motors".

## Data model

No persistence. Inventory is a hardcoded JS array of 8 cars:

```js
const inventory = [
  { id, year, make, model, trim, price, mileage, body, fuel, mpg, image, badge? },
  …
]
```

Curated mix: 2 SUVs, 2 sedans, 1 truck, 1 EV, 1 coupe, 1 hatchback. Price range $14k–$58k for credibility. Each gets a real photo URL.

Financing calculator is pure state in JS (no library) — `monthly = principal * r / (1 - (1+r)^-n)` where r = APR/12 and n = months. Default APR shown as 6.9%.

## User flows

1. **Landing → browse** — visitor lands on hero, scrolls to inventory grid, hovers cards, clicks "View details" (scrolls to contact form prefilled with car name; no detail page since this is a landing page).
2. **Landing → financing** — visitor opens financing section, drags price/down/term inputs, sees monthly update live.
3. **Landing → contact** — visitor fills form, gets inline validation, sees success toast on submit.
4. **Mobile** — nav collapses to hamburger, hero stacks photo below copy, inventory grid becomes 1-col then 2-col, financing calculator stacks.

## Files to create

```
sara-motors/
├── index.html              # the whole page, semantic sectioning
├── styles/
│   ├── base.css            # reset, tokens (CSS variables), typography
│   ├── layout.css          # nav, sections, grid, footer
│   └── components.css      # cards, buttons, forms, calculator, badges
├── scripts/
│   ├── main.js             # nav toggle, scroll reveals, smooth scroll
│   ├── inventory.js        # render the 8 cards from the data array
│   ├── financing.js        # calculator logic + live update
│   └── contact.js          # form validation + success toast
├── data/
│   └── inventory.js        # the 8-car dataset
├── assets/
│   └── logo.svg            # simple wordmark "SARA" + small car silhouette
├── package.json            # vite as dev dep, "dev" and "build" scripts
├── vite.config.js          # minimal config, root = ./
└── README.md               # how to run, what's where, how to swap inventory
```

No framework, no Tailwind, no UI library — hand-rolled CSS with CSS variables for tokens. Keeps it portable, easy to hand off, no node_modules required to view (open `index.html` directly works too).

## Verification targets

After CODE mode builds it:

1. `npm run build` produces a `dist/` with no errors.
2. Open `dist/index.html` in a browser — page renders without console errors.
3. **Hero** loads with photo, price card, both CTAs visible above the fold at 1440×900.
4. **Inventory** grid renders all 8 cars with photos loaded (no broken images).
5. **Filter chips** visually toggle active state (even if filtering is decorative).
6. **Financing calculator** — changing price/down/term updates monthly payment live with correct math (spot-check: $30k, $3k down, 60mo, 6.9% APR → ~$534/mo).
7. **Contact form** — submitting empty shows validation errors; submitting valid shows success toast and clears form.
8. **Mobile** — at 375px width, nav collapses, hero stacks, inventory becomes 1-col, no horizontal scroll.
9. **Lighthouse** — Performance ≥ 90, Accessibility ≥ 95 on a local run.
10. **Click test** — every nav link and CTA scrolls to the right section.
