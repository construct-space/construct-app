# Plan — Construct landing page

## Classification

Static marketing site. Single-page, tight scope (5 sections). Built with Astro for component reuse + near-zero JS shipped. No backend, no auth, no persistence — a contact/email-capture form posts to a third-party endpoint (Formspree or similar) configured later.

## Identity

- **Product**: Construct — model-agnostic AI assistant + desktop app organized around Spaces.
- **Visual direction**: Modern SaaS (Linear / Vercel lineage).
  - Dark canvas (`#0A0A0B` base, `#111114` cards).
  - Near-monochrome neutrals (`#F4F4F5` foreground, `#71717A` muted).
  - Single bold accent — proposed `#7C5CFF` (electric violet). Confirm in CODE.
  - Subtle radial gradient glow behind hero.
  - One workhorse sans: Inter (or Geist Sans if available locally) for everything; JetBrains Mono for inline code/keystrokes.
- **Tone**: Confident, concrete, no buzzwords. Short sentences. Verbs first.
- **Motion**: Restrained — fade/translate on scroll-into-view, no parallax, no autoplay video. Respect `prefers-reduced-motion`.

## Pages

Single route: `/`.

### Sections (in order)

1. **Nav** — left: Construct wordmark. Right: `Spaces`, `Pricing`, `Sign in`, `Download` (primary). Sticky, blurred backdrop on scroll.
2. **Hero**
   - Eyebrow: "The AI workspace that ships with apps."
   - Headline (2 lines max): "One assistant. Every workflow. Built on Spaces."
   - Sub: 1–2 sentences explaining model-agnostic + Spaces in plain English.
   - Primary CTA: `Download for Mac`. Secondary: `See how it works` (anchor to section 3).
   - Visual: stylized product shot — dark app chrome with Construct sidebar + an open Space. SVG mock, not a real screenshot.
3. **Spaces showcase** — "Spaces are little apps inside Construct."
   - Grid of 6 cards: Mail, Calendar, Notes, CRM, PM, Sheets. Each card = icon + name + 1-line role.
   - Footer line: "…and dozens more. Build your own with the CLI."
4. **How it works** — 3 numbered steps, large numerals, hairline dividers.
   - 01 Install Construct. 02 Connect your Spaces. 03 Ask Construct anything.
5. **Pricing teaser** — single card or two-tier:
   - Free — for individuals, X Spaces included.
   - Team — per seat, all Spaces, org features.
   - CTA: `See full pricing →` (links to `#` for now).
6. **CTA + Footer**
   - Final CTA band: "Stop switching apps. Start shipping." + `Download` button.
   - Footer: small wordmark, columns (Product / Company / Legal), copyright, no social maximalism.

## Data model

None. All content is hard-coded in `.astro` components or a single `src/content/site.ts` data file for easy editing (Spaces list, pricing rows, nav links). Form submissions out of scope for v1.

## User flows

- Land → scroll → hit Download CTA. That's the success path.
- Land → click nav `Spaces` → smooth-scroll to section 3.
- Land → click `See how it works` → smooth-scroll to section 4.
- Keyboard: tab order matches visual order, focus rings visible against dark bg.

## Verification targets

- `pnpm install` (or `npm install`) completes clean.
- `pnpm dev` serves `/` without console errors.
- `pnpm build` produces `dist/` with hashed assets.
- Open `dist/index.html` in a browser:
  - All 5 sections render, in order, with the right copy.
  - Nav anchor links scroll to correct sections.
  - Download CTA buttons are clickable (href can be `#` for v1).
  - Layout holds at 360px, 768px, 1280px, 1920px widths.
  - No layout shift on font load (Inter preloaded with `font-display: swap`).
- Lighthouse on built output: Performance ≥ 95, Accessibility ≥ 95, Best Practices ≥ 95.
- `prefers-reduced-motion: reduce` disables scroll-reveal transitions.
- Contrast check: foreground vs background ≥ 7:1, muted text ≥ 4.5:1, accent button text ≥ 4.5:1.
