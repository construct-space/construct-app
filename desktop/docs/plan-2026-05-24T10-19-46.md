# Plan — Sara Motors landing page

## Classification

Single-page marketing site for a car dealership called **Sara**. Not a Construct Space, not a web app — a static landing page. Built as plain HTML + CSS + a small amount of vanilla JS for interactions (mobile nav, scroll reveals, financing calculator, contact form validation). Vite is used for dev/build ergonomics; output is a static `dist/` that can be hosted anywhere.

Aesthetic: **modern SaaS / trust-tech**. Reference points: Carvana, Vroom, modern dealer chains — light theme, one bold accent color, soft gradients, big hero photo, structured inventory grid.

## Identity

- **Brand name**: Sara Motors
- **Tagline**: "Find your next car. Without the dealership games."
- **Voice**: confident, transparent, low-pressure. No exclamation marks, no "DEALS DEALS DEALS". Promises clarity, fair pricing, no-haggle process.
- **Palette**:
  - Background: `#FFFFFF` primary, `#F7F8FA` alt section
  - Ink: `#0B1220` near-black, `#4B5563` secondary, `#9CA3AF` muted
  - Accent: `#2563EB` electric blue (trust + tech), `#1D4ED8` hover, `#EFF4FF` tint surface
  - Success / badge accent: `#059669`
- **Type**: **Inter** throughout — 700/600 for display + headings, 400/500 for body. Tabular numerals for prices and specs.
- **Imagery**: high-quality car photography on neutral backgrounds. Curated Unsplash URLs so the page renders without bundling local assets.

## Pages

Single page, anchor-navigated:

1. `/` — sections in order:
   - **Nav** — sticky, glass-on-scroll. Wordmark + links: Inventory, Financing, About, Contact + primary CTA "Browse Inventory".
   - **Hero** — left: H1 + subhead + two CTAs ("Browse Inventory", "Get pre-approved"). Right: hero car photo with floating "price card" overlay (price, mileage, year, MPG). Trust strip: "1,200+ cars sold · 4.9★ on Google · 7-day return policy".
   - **Value props** — 3-column: *Upfront pricing* / *7-day returns* / *Financing in minutes*. Icon + headline + 1-sentence body each.
   - **Inventory showcase** — header "Featured inventory" + filter chips (All / SUV / Sedan / Truck / EV — decorative). Grid of **8 car cards**: photo, year + make + model, price (large, tabular), mileage, body type, "View details" link. Hover lift.
   - **How it works** — 3-step horizontal timeline: *Browse* → *Test drive at home* → *Buy online or in person*.
   - **Financing** — split section: left a calculator card (price, down payment, term, APR → monthly, all client-side math), right copy on financing partners + soft-pull messaging.
   - **Testimonials** — 3 quote cards with name + city + star rating.
   - **About Sara** — 2-column: photo + short founder story. Stats row: years in business / cars sold / average rating.
   - **Contact / CTA** — gradient panel. Form: name, email, phone, message. Client-side validation, success toast, no real POST.
   - **Footer** — logo, address, phone, hours, social links, secondary nav, copyright.

## Data model

No persistence. All data is hardcoded.

- **Inventory** — JS array of 8 cars:
  ```js
  { id, year, make, model, trim, price, mileage, body, fuel, mpg, image, badge? }
  ```
  Curated mix: 2 SUVs, 2 sedans, 1 truck, 1 EV, 1 coupe, 1 hatchback. Price range ~$14k–$58k.
- **Financing calculator** — pure JS state:
  `monthly = principal * r / (1 - (1 + r)^-n)`, where `r = APR / 12 / 100`, `n = term_months`. Default APR 6.9%.
- **Contact form** — local state only; submission logs to console + shows success toast.

## User flows

1. **Landing → browse inventory** — visitor scrolls hero → grid, hovers cards, clicks "View details" → smooth-scrolls to contact form (no per-car detail page).
2. **Landing → financing** — visitor adjusts price / down / term sliders, sees monthly update live.
3. **Landing → contact** — fills form, inline validation on blur, success toast on submit, form clears.
4. **Mobile (≤640px)** — nav collapses to hamburger; hero stacks photo below copy; inventory becomes 1-col then 2-col; calculator stacks; no horizontal scroll.

## Verification targets

After CODE mode builds it:

1. `npm install` + `npm run build` produces `dist/` with no errors.
2. Open `dist/index.html` — page renders, **no console errors**.
3. **Hero** renders with photo, floating price card, both CTAs visible above the fold at 1440×900.
4. **Inventory grid** renders all 8 cars; all photos load (no broken images).
5. **Filter chips** visually toggle active state on click.
6. **Financing calculator** — adjusting price / down / term updates monthly live. Spot-check: $30,000 price, $3,000 down, 60mo, 6.9% APR → ~$534/mo (±$2).
7. **Contact form** — empty submit shows inline errors; valid submit shows success toast + clears form.
8. **Mobile** — at 375px width: nav collapses to hamburger that opens/closes; hero stacks; grid is 1-col; no horizontal overflow.
9. **Lighthouse** — Performance ≥ 90, Accessibility ≥ 95 on a local run of the built site.
10. **Nav click test** — every nav link + CTA scrolls to the correct section.
