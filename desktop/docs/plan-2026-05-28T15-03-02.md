# Plan — Construct landing page

## Classification

Marketing site. Single-page, tight (5 sections). Modern SaaS aesthetic in the
Linear / Vercel lineage — dark canvas, one bold accent, soft glow, generous
whitespace, gradient hero. Built with **Astro** so we get component
composition, ~zero shipped JS by default, and an easy on-ramp if a blog or
/changelog gets added later.

Not a Construct Space — this is a standalone web project that lives in its
own directory, gets built to static HTML, and deploys anywhere (Netlify,
Vercel, S3, GitHub Pages).

## Identity

- **Product**: Construct — the desktop app that ships a workspace of
  installable Spaces (Mail, Calendar, Notes, CRM, PM, …) with an AI
  assistant that can read, act, and build across all of them.
- **One-line positioning**: "Your workspace, with an agent that actually
  does the work."
- **Tone**: confident, technical-but-not-jargon-heavy, slightly opinionated.
  No "revolutionize", no "leverage", no "AI-powered" filler.
- **Audience**: founders, operators, and engineers who already live in
  Linear / Notion / Superhuman and want fewer tabs + a real assistant.

## Visual system

| Token | Value |
|---|---|
| Background | `#0A0A0B` (near-black, slight warmth) |
| Surface | `#111114` for cards, `#16161A` for elevated |
| Foreground | `#F5F5F7` primary, `#A1A1AA` secondary, `#52525B` muted |
| Accent | `#7C5CFF` (violet) with `#A78BFA` lighter and `#5B3FD9` darker |
| Accent glow | `radial-gradient(ellipse, rgba(124,92,255,0.35), transparent 60%)` |
| Border | `rgba(255,255,255,0.06)` hairline, `rgba(255,255,255,0.12)` hover |
| Type — display | Inter Tight, 600/700, tight tracking (-0.02em) |
| Type — body | Inter, 400/500, 1.55 line-height |
| Type — mono | JetBrains Mono (for inline tags like `Cmd+K`) |
| Radius | 12px cards, 8px buttons, 4px chips |
| Shadow | None hard — use glow + subtle inner border instead |
| Max width | 1200px container, 720px reading column |
| Section padding | 120px desktop / 64px mobile vertical |

Single accent rule: violet appears only on primary CTA, key highlights,
hero gradient. Everything else is the neutral scale.

### 3. How it works
- Section eyebrow: `02 — How it works`
- H2: "Talk to it. It does the thing."

  1. **Ask** — natural language, no command palette gymnastics.
     Example: *"Summarize unread mail from this week and draft replies to
     the urgent ones."*
  2. **Act** — the assistant calls the right Spaces, reads what it needs,
     drafts, schedules, edits.
  3. **Review** — every action is surfaced before it sends. You stay in
     control.
- Visual: stylized chat-bubble + arrow flowing into Space icons.

### 5. CTA + footer

## Data model

None. Fully static. No forms, no Graph, no localStorage. The "Download"
button is a placeholder `<a href="#">` for now; we'll wire it to an
actual artifact link later.

## User flows

- **First-time visitor lands** → reads hero → scrolls → clicks Download
  (placeholder).
- **Returning visitor** → uses top nav to jump to Pricing or Spaces.
- Smooth-scroll anchor nav between sections. No router needed.

Tooling choices:
- Astro 4.x, no UI framework integration (no React/Vue) — pure .astro
  components.
- Plain CSS with custom properties for tokens (no Tailwind — keeps the
  surface small and the design intentional).
- Fonts: Inter + Inter Tight + JetBrains Mono via Fontsource (self-hosted,
  no Google Fonts CDN).
- TypeScript on by default for any `<script>` blocks.

## Verification targets

After build (`npm run build`):
1. `dist/index.html` exists and is < 60KB (gzipped well under 20KB).
2. Open `dist/index.html` in a headless browser — no console errors,
   all sections render, fonts load.
3. Lighthouse mobile: Performance ≥ 95, Accessibility ≥ 95, Best
   Practices ≥ 95, SEO ≥ 95.
4. Anchor links (`#spaces`, `#how`, `#pricing`) all resolve and
   smooth-scroll.
5. Visual spot-check:
   - Hero gradient glow is visible behind the screenshot mock.
   - Violet accent appears only on primary CTAs and hero highlight.
   - Cards have hairline borders (no harsh shadows).
   - Type scale steps consistently — H1 > H2 > H3 > body.
   - 320px width: nothing overflows, nav collapses to a single CTA.
6. Manual contrast check: every text/background pair ≥ 4.5:1 (WCAG AA).
