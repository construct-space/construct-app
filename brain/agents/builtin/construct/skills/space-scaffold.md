# Scaffolding a Construct Space

Always scaffold first. Do not hand-build the structure.

## Command

```bash
construct scaffold <kebab-name>
# aliases: construct new, construct create
```

Or via the space tool:

```
space_create { name: "<kebab-name>", project: "<absolute project path>" }
```

## Resulting Layout

```
{project}/
  space-{name}/
    space.manifest.json
    package.json
    vite.config.ts
    tsconfig.json
    src/
      entry.ts            # auto-generated on build
      pages/
        index.vue         # default page
      components/
      composables/
      models/             # Graph models (if needed)
      actions.ts          # optional
    agent/
      config.md
      skills/default.md
      tools/              # optional
    widgets/
      summary/
        2x1.vue
        4x1.vue
    dist/                 # build output
```

## package.json (always)

The scaffold template is the source of truth —
`operator/internal/spacedev/scaffold/templates/package.json.tmpl`.
Construct SDK packages (`@construct-space/sdk`, `@construct-space/ui`,
`@construct-space/graph`) and the CLI are pinned to `"latest"` so
scaffolds never drift from the currently-published versions. Shape:

```json
{
  "name": "@construct-spaces/space-{name}",
  "version": "0.1.0",
  "private": true,
  "type": "module",
  "scripts": {
    "build": "construct space build",
    "dev": "construct space dev",
    "check": "vue-tsc --noEmit && eslint .",
    "validate": "construct space validate"
  },
  "peerDependencies": {
    "vue": "^3.5.0",
    "pinia": "^3.0.0",
    "@vueuse/core": "^14.0.0"
  },
  "dependencies": {
    "vue-router": "^4.5.0",
    "@construct-space/sdk": "latest",
    "@construct-space/ui": "latest",
    "@construct-space/graph": "latest",
    "lucide-vue-next": "^1.0.0"
  },
  "devDependencies": {
    "@construct-space/cli": "latest",
    "vite": "^6.3.5",
    "@vitejs/plugin-vue": "^5.2.3",
    "typescript": "^5.9.3",
    "vue-tsc": "^3.2.5"
  }
}
```

Do NOT run `bun install` immediately after scaffolding — it pulls ~140MB
of dev toolchain (vite, @vitejs/plugin-vue, vue-tsc) and most simple Spaces
don't need that until the user asks to build or preview. `space_build` will
install lazily on first use if `node_modules` is missing.

## vite.config.ts (IIFE)

```ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'path'

export default defineConfig({
  plugins: [vue()],
  build: {
    lib: {
      entry: resolve(__dirname, 'src/entry.ts'),
      name: '__CONSTRUCT_SPACE_{ID_UPPER}',
      fileName: 'space-{id}',
      formats: ['iife'],
    },
    rollupOptions: {
      external: ['vue', 'vue-router', 'pinia', '@vueuse/core'],
      output: {
        globals: {
          vue: 'window.__CONSTRUCT__.vue',
          'vue-router': 'window.__CONSTRUCT__["vue-router"]',
          pinia: 'window.__CONSTRUCT__.pinia',
          '@vueuse/core': 'window.__CONSTRUCT__["@vueuse/core"]',
        },
      },
    },
  },
  resolve: { alias: { '~': resolve(__dirname), '@': resolve(__dirname, 'src') } },
})
```

Never bundle Vue/Pinia/vue-router/vueuse. The host provides them via `window.__CONSTRUCT__`.

## Manifest Minimum

```json
{
  "id": "my-space",
  "name": "My Space",
  "version": "0.1.0",
  "description": "What it does",
  "icon": "i-lucide-layout-dashboard",
  "scopes": ["app"],
  "navigation": {
    "label": "My Space",
    "icon": "i-lucide-layout-dashboard",
    "to": "/",
    "order": 50
  },
  "pages": [
    { "path": "/", "label": "Home", "default": true }
  ],
  "permissions": [
    { "key": "items.read", "label": "View items", "description": "Read items list" }
  ],
  "agent": "agent/config.md"
}
```

Do not use `spaceId`, `displayName`, or `routes` — those are wrong field names. Use `scopes` (array), never singular `scope`. `permissions` is optional but recommended for `['org']` spaces so admins can grant/revoke roles; each entry needs `key`, `label`, `description`.

## entry.ts Shape

Auto-generated by `construct build`. If you need to understand it:

```ts
import IndexPage from './pages/index.vue'
import SettingsPage from './pages/SettingsPage.vue'
import Widget2x1 from '../widgets/summary/2x1.vue'
import { actions } from './actions'

export default {
  pages: {
    '': IndexPage,
    '/settings': SettingsPage,
  },
  widgets: {
    'widget-id': { '2x1': Widget2x1 },
  },
  actions,
}
```

## Post-Scaffold Checklist

1. Read `space.manifest.json`, `package.json`, `vite.config.ts`, `src/pages/index.vue`
2. If Graph is needed: `space_graph_init` immediately (or `construct graph init` outside the operator tool surface)
3. Begin implementation — edit source files directly
4. When the user asks to build/preview, call `space_build` (it installs
   deps lazily if `node_modules` is missing)
